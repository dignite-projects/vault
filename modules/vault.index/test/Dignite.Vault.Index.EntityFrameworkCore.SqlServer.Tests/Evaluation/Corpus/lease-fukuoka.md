# 住宅賃貸借契約書

賃貸人 博多ホーム株式会社(以下「甲」という)と賃借人 佐藤花子(以下「乙」という)は、次のとおり住宅の賃貸借契約を締結する。

## 第1条(物件)

福岡市中央区薬院三丁目 8 番 2 号「薬院パークハウス」305 号室(2LDK)。

## 第2条(賃料)

賃料は月額 76,000 円、管理費は月額 5,000 円とし、乙は毎月 27 日までに翌月分を口座振替により支払う。

## 第3条(更新料)

契約を更新するときは、乙は更新料として新賃料の一か月分を甲に支払う。

## 第4条(禁止事項)

乙は、甲の書面による承諾を得ないで、次の行為をしてはならない。

- 犬、猫その他の動物を飼育すること
- 本物件の全部又は一部を転貸すること
- 楽器の演奏その他近隣に迷惑を及ぼす行為をすること

## 第5条(契約期間)

契約期間は 2026年10月1日から 2028年9月30日までとする。
