# 秘密保持契約書

株式会社ディグナイト(以下「甲」という)と株式会社さくらテック(以下「乙」という)は、両社間の業務提携の検討に関して開示される情報の取扱いについて、次のとおり契約を締結する。

## 第1条(秘密情報の定義)

秘密情報とは、開示者が書面又は電磁的方法により秘密である旨を明示して開示した技術上又は営業上の情報をいう。口頭で開示した情報は、開示後 30 日以内に書面で特定したものに限る。

## 第2条(秘密情報から除かれるもの)

次の情報は秘密情報に含まれない。開示時に既に公知であったもの、受領者の責めによらず公知となったもの、受領者が独自に開発したもの。

## 第3条(目的外使用の禁止)

受領者は、秘密情報を業務提携の検討以外の目的に使用してはならない。

## 第4条(返還及び廃棄)

受領者は、本契約が終了したとき又は開示者から請求があったときは、秘密情報を記録した媒体を返還し、又は廃棄しなければならない。

## 第5条(有効期間)

本契約の有効期間は締結日から三年間とする。ただし、第3条の義務は本契約終了後も二年間存続する。
