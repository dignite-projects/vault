# 情報セキュリティ委員会 議事録

日時: 2026年11月5日 15:00〜16:00
出席者: 委員長 伊藤、情報システム部 山本、総務部 田中、開発部 渡辺

## 議題1 パスワードポリシーの改定

パスワードの定期変更(90 日ごと)を廃止し、12 文字以上かつ多要素認証の必須化に改めることを決定した。2027年1月から適用する。

## 議題2 標的型メール訓練の結果

10 月に実施した訓練メールの開封率は 18%、添付ファイルの実行率は 4% であった。実行した社員には個別に研修を行う。

## 議題3 USB メモリの使用制限

社用 PC での USB メモリの使用を原則禁止とし、業務上必要な場合は暗号化 USB メモリを貸与する。
