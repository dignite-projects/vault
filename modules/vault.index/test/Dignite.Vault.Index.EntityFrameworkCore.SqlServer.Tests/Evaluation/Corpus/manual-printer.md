# 複合機 X-500 取扱説明書

## 1. 各部の名称

操作パネルは本体前面右側にあります。用紙トレイは上から順にトレイ 1、トレイ 2 です。手差しトレイは本体右側面にあります。

## 2. トナーの交換

1. 前面カバーを開けます。
2. 交換ランプが点滅しているトナーカートリッジを手前に引き抜きます。
3. 新しいカートリッジを 5、6 回振ってから、奥まで差し込みます。
4. 前面カバーを閉じます。

## 3. 紙詰まりの処理

操作パネルに「E-12」が表示されたときは、用紙搬送部で紙が詰まっています。右側面カバーを開け、緑色のレバーを下げてから詰まった用紙をゆっくり引き抜いてください。

## 4. エラーコード一覧

| コード | 内容 | 対処 |
|---|---|---|
| E-12 | 搬送部の紙詰まり | 右側面カバーを開けて用紙を取り除く |
| E-31 | トナー残量なし | トナーを交換する |
| E-58 | 定着ユニットの温度異常 | 電源を切り、30 分後に入れ直す。再発時はサービスに連絡 |

## 5. 省エネ設定

最後の操作から 15 分で節電モードに入ります。設定メニューの「省エネ」から時間を変更できます。
