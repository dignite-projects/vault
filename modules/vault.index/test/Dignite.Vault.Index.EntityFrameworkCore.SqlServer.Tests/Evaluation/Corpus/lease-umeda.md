# 事務所賃貸借契約書

賃貸人 梅田ビルディング株式会社(以下「甲」という)と賃借人 株式会社青空商事(以下「乙」という)は、事務所の賃貸借について次のとおり合意する。

## 第1条(物件)

大阪市北区梅田二丁目 4 番 9 号「梅田センタービル」12 階 1201 区画(契約面積 186.5 平方メートル)を、事務所として使用する目的で賃貸する。

## 第2条(賃料及び共益費)

賃料は月額 420,000 円、共益費は月額 56,000 円とし、乙は毎月 25 日までに当月分を支払う。

## 第3条(保証金)

乙は保証金として賃料の六か月分 2,520,000 円を差し入れる。明渡し時に償却費として賃料一か月分を差し引いて返還する。

## 第4条(契約期間)

契約期間は 2027年1月1日から 2029年12月31日までの三年間とする。

## 第5条(中途解約)

乙は六か月前までに書面で予告することにより、本契約を解約することができる。予告に代えて六か月分の賃料を支払うことで即時に解約できる。

## 第6条(内装工事)

乙が内装工事を行うときは、事前に工事計画書を甲に提出し、書面による承諾を得なければならない。
