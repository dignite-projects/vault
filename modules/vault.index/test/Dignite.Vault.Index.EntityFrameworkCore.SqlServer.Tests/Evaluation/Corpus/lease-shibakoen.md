# 建物賃貸借契約書

賃貸人 株式会社ディグナイト不動産(以下「甲」という)と賃借人 山田太郎(以下「乙」という)は、次のとおり建物賃貸借契約を締結する。

## 第1条(目的)

甲は乙に対し、東京都港区芝公園一丁目 3 番 5 号所在の共同住宅「芝公園レジデンス」702 号室を、住居として賃貸する。

## 第2条(賃料)

賃料は月額 185,000 円とし、乙は毎月末日までに翌月分を甲の指定する口座に振り込む。振込手数料は乙の負担とする。

## 第3条(敷金)

乙は本契約締結時に敷金として賃料の二か月分 370,000 円を甲に預け入れる。敷金には利息を付さない。

## 第4条(契約期間)

契約期間は 2026年12月1日から 2028年11月30日までの二年間とする。期間満了の三か月前までに双方から申出がないときは、同一条件で更新する。

## 第5条(原状回復)

乙は本契約終了時に、通常の使用による損耗を除き、本物件を原状に回復して甲に明け渡す。
